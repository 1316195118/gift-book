# 礼簿封面原创底图

本目录中的 WebP 文件是 2026-11-27 为本项目专门生成的原创底图，
使用火山方舟 `doubao-seedream-5.0-pro` 文本生图能力制作。它们不是从
现成礼簿、影视海报、插画师作品或图库中截取、描摹或合成的素材。

生成约束：

- 只绘制中国丝绸、漆面、纸本、花鸟、松柏、窗棂和山水等通用传统纹样。
- 不指定或模仿任何在世艺术家、品牌、影视作品、出版物或具体历史封面。
- 画面内不生成人物、商号、题字、印章、数字、水印或第三方标识。
- 书名、场景名、祝辞与落款印章全部由应用运行时绘制，图片本身只承担材质和装饰。
- 保留中央或中上部留白，便于题签、书名和日期形成清晰层级。

| `white-pine-mist.webp` | 月白绢面、远山松柏与淡墨竹影，用于追思和纪念 |

`red-wedding-phoenix-warm.webp` 与 `red-house-lattice-warm.webp` 是在对应原始
底图上做的暖色暗部修正版：只把中性黑灰暗部重映射为深朱红和胭脂红，保留原有
花鸟、窗棂、纸纹与金色纹样。生产代码使用这两张修正版，避免缩略封面出现突兀
黑块；原始生成图继续作为母版保留。

`white-chrysanthemum-v2.webp` 的生成提示词：
